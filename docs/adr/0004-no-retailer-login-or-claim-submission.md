# ADR 0004 — No Retailer Login or Claim Submission

**Status:** Accepted  
**Date:** 2026-07-13

## Decision

AfterBuy will not collect Target credentials, log into Target accounts, or submit price-match requests in the MVP.

## Consequences

- The user remains in control.
- AfterBuy provides monitoring, evidence, timing, and official instructions.
- Target independently verifies and decides every request.
